# 02-PROJECTS

One folder per project: `overview.md` + `tasks.md`. Code never lives here. Each overview points to the branch that holds the code.

## overview.md template

```markdown
# [Project]

## Brief
One paragraph.

## Status
Idea / Spec / Building / Review / Live

## Code
Repo and branch.

## Milestones
- [ ] ...

## Decisions
- YYYY-MM-DD: decision, and why

## Blockers
- ...

## Next action
- ...
```

## tasks.md template

```markdown
# [Project]: tasks

## Active
- [ ] ...

## Done
- [x] YYYY-MM-DD ...
```

Always log the blocker and the next step, not just what was done.
