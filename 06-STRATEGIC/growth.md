# Growth

## How families find us
- Mostly referrals. The brochure is shared as a PDF on WhatsApp.
- Swarit's direction: ask relatives and friends to refer other families rather than enrol their own kids.
- Order: send referral message 1 or 2, then 3 (ready to forward). Texts: `04-CONTENT/whatsapp/referral-messages.md`.
- Put the relative's name in [Name] in message 3 so referrals can be tracked.

## Funnel
WhatsApp message → greeting → booking link → 10-minute test → result → $150 reserve → $450 balance → kit ships.
Tracked in `01-FAMILIES/leads.md`.
