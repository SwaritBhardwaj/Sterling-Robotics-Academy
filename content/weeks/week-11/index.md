> Can I explain every line of what my robot is doing?

## By the end of this week
- A complete submission package
- Code you can explain section by section
- The brief for the final video

## Have ready for class
- Robot charged
- Latest code and tuning log open

## Assignment

### Must: Final code
One .ino with a comment heading each section: read sensor, angle, error, P, D, I, cut-off, motors.

### Must: The bar, on video
Up to 45 s, one take: 30 seconds standing, then three taps.

### Must: Final values and reflection
Fill in and paste as text.

```
FINAL VALUES
Balance point: ____°   Kp: ____   Kd: ____   Ki: ____
Cut-off angle: ____°   Dead zone L / R: ____ / ____

REFLECTION
1. What was hardest?
2. Which bug took longest, and how did you find it?
3. In your own words, what does D do?
4. If you rebuilt it, what would you change?
5. What do you want to build next?
```

### Must: Oral check
In your 1:1 this week, explain your code section by section in about 5 minutes.

## Before you submit, check
- Stands 30 seconds hands-free
- Recovers from three taps
- Every section of the code has a comment
- Explains P and D in the 1:1 without notes
- Reflection complete
