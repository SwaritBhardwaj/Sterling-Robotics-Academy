What we teach.

```
overview.md          course map: the 12 weeks, approach, schedule rules, week page format
teaching-guide/      teacher-facing lesson plans, one file per week (source for the student pages)
```

**Where student pages live:** the site repo, `content/weeks/week-NN/index.md`. They are written from the teaching guide in student language, with teacher-only notes left out. They are not copied here, so there is one source each (see `TODOS.md`).

**When a lesson changes:** edit the teaching guide here first, then the student page in the site repo, then log both.
