## Logging
"Received $150 from [family] for reserve" → append to `revenue.md`, update the family file and `01-FAMILIES/leads.md`, recompute the cohort total.
"Paid $X to [vendor] for [thing]" → append to `expenses.md`.

Log costs as well as revenue. A margin with no recorded costs is fiction.
